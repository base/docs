---
title: "subscription.prepareCharge"
description: "Prepare transaction calls to charge a subscription"
---

Defined in the [Base Account SDK](https://github.com/base/account-sdk)

<Info>
The `prepareSubscriptionCharge` function prepares the necessary transaction calls to charge a subscription. It returns the call data needed to execute the charge through `wallet_sendCalls`. This gives you full control over when and how to execute subscription charges.
</Info>

## Parameters

<ParamField body="id" type="string" required>
The subscription ID (permission hash) returned from subscribe().

**Pattern:** `^0x[0-9a-fA-F]{64}$`
</ParamField>

<ParamField body="amount" type="string | 'max-remaining-charge'" required>
Amount to charge (e.g., "10.50") or 'max-remaining-charge' for the full remaining amount in the current period.
</ParamField>

<ParamField body="testnet" type="boolean">
Must match the testnet setting used in the original subscribe call. Default: false
</ParamField>

## Returns

<ResponseField name="result" type="PrepareChargeResult">
Array of transaction calls to execute the charge.

<Expandable title="PrepareChargeCall properties">
<ResponseField name="to" type="Address">
The address to call (smart contract address).
</ResponseField>

<ResponseField name="data" type="Hex">
The encoded call data for the transaction.
</ResponseField>

<ResponseField name="value" type="'0x0'">
The value to send (always 0x0 for spend permissions).
</ResponseField>
</Expandable>
</ResponseField>

The returned array contains:
- An approval call (if the permission is not yet active)
- A spend call to charge the subscription

<RequestExample>
```typescript Charge Specific Amount
import { base } from '@base-org/account';

// Prepare to charge a specific amount
const chargeCalls = await base.subscription.prepareCharge({
  id: '0x71319cd488f8e4f24687711ec5c95d9e0c1bacbf5c1064942937eba4c7cf2984',
  amount: '9.99',
  testnet: false
});

// Execute the charge using wallet_sendCalls
const result = await provider.request({
  method: 'wallet_sendCalls',
  params: [{
    version: '2.0.0',
    atomicRequired: true,
    from: subscriptionOwner, // Must be the subscription owner!
    chainId: '8453', // Base mainnet
    calls: chargeCalls,
  }],
});

console.log(`Charge transaction: ${result}`);
```

```typescript Complete Charge Workflow
import { base } from '@base-org/account';

async function chargeSubscription(
  subscriptionId: string,
  subscriptionOwner: string,
  provider: any
) {
  try {
    // 1. Check subscription status first
    const status = await base.subscription.getStatus({
      id: subscriptionId,
      testnet: false
    });
    
    if (!status.isSubscribed) {
      throw new Error('Subscription is not active');
    }
    
    const remainingAmount = parseFloat(status.remainingChargeInPeriod || '0');
    
    if (remainingAmount === 0) {
      console.log(`No charge available until ${status.nextPeriodStart}`);
      return null;
    }
    
    // 2. Prepare the charge
    const chargeCalls = await base.subscription.prepareCharge({
      id: subscriptionId,
      amount: 'max-remaining-charge', // Charge what's available
      testnet: false
    });
    
    console.log(`Preparing to charge $${remainingAmount}`);
    
    // 3. Execute the charge
    const result = await provider.request({
      method: 'wallet_sendCalls',
      params: [{
        version: '2.0.0',
        atomicRequired: true,
        from: subscriptionOwner,
        chainId: '8453',
        calls: chargeCalls,
      }],
    });
    
    console.log(`✅ Successfully charged $${remainingAmount}`);
    console.log(`Transaction: ${result}`);
    
    return result;
    
  } catch (error) {
    console.error(`❌ Charge failed: ${error.message}`);
    throw error;
  }
}
```

## Important Notes

<Warning>
**Critical Requirements:**
- The `from` address in `wallet_sendCalls` MUST be the subscription owner address
- Only the subscription owner can execute charges
- The subscription must be active (not cancelled)
</Warning>

## Usage Patterns

<Tabs>
<Tab title="Backend Charging">
Execute charges from your backend service:

```typescript
// Backend service with subscription owner wallet
async function processMonthlyCharges() {
  const subscriptions = await getActiveSubscriptions();
  
  for (const sub of subscriptions) {
    const chargeCalls = await base.subscription.prepareCharge({
      id: sub.id,
      amount: sub.monthlyAmount,
      testnet: false
    });
    
    await executeCharge(chargeCalls, sub.owner);
  }
}
```
</Tab>

<Tab title="Partial Charges">

```typescript
const status = await base.subscription.getStatus({ id, testnet });
const remaining = parseFloat(status.remainingChargeInPeriod || '0');
const desired = parseFloat(chargeAmount);

const actualCharge = Math.min(remaining, desired);

if (actualCharge > 0) {
  const calls = await base.subscription.prepareCharge({
    id,
    amount: actualCharge.toFixed(2),
    testnet
  });
  // Execute charge
}
```
</Tab>

<Tab title="Retry Logic">
Implement retry logic for failed charges:

```typescript
async function chargeWithRetry(subscriptionId: string, maxRetries = 3) {
  for (let attempt = 1; attempt <= maxRetries; attempt++) {
    try {
      const calls = await base.subscription.prepareCharge({
        id: subscriptionId,
        amount: 'max-remaining-charge',
        testnet: false
      });
      
      const result = await executeCharge(calls);
      return result;
      
    } catch (error) {
      console.log(`Attempt ${attempt} failed: ${error.message}`);
      
      if (attempt === maxRetries) {
        throw error;
      }
      
      // Wait before retry
      await new Promise(resolve => setTimeout(resolve, 2000 * attempt));
    }
  }
}
```
</Tab>

## Error Handling

```typescript
try {
  const chargeCalls = await base.subscription.prepareCharge({
    id: subscriptionId,
    amount: chargeAmount,
    testnet: false
  });
  // Execute charge
} catch (error) {
  if (error.message.includes('insufficient')) {
    console.error('Not enough remaining charge in period');
  } else if (error.message.includes('cancelled')) {
    console.error('Subscription has been cancelled');
  } else {
    console.error(`Failed to prepare charge: ${error.message}`);
  }
}
```
