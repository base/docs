Submits one signed, serialized EIP-8130 transaction with predicates that control when the transaction is eligible for inclusion. The method returns the signed transaction hash when the endpoint accepts the submission.

<Warning>
This method is experimental and is available only on RPC endpoints that explicitly enable validity transactions. Supported endpoints and rate limits will be published before general availability.
</Warning>

The EIP-8130 validity window and network tip are part of the signed transaction. The second RPC parameter contains only the builder validity predicates.

## Parameters

<ParamField body="transaction" type="string" required>
  One signed, serialized EIP-8130 transaction encoded as a `0x`-prefixed hex string.

  The transaction contains its validity window, fee fields, gas limit, call phases, network tip, and authentication data. Changing any of those fields requires a new signature and produces a new transaction hash.
</ParamField>

<ParamField body="options" type="object" required>
  Options transported with the transaction to the builder. These options are not part of the signed EIP-8130 transaction body.

  <Expandable title="Options">
    <ParamField body="validity" type="array" required>
      One or more validity predicates. The builder combines predicates with logical AND, so every predicate must match at the same candidate insertion point.

      The endpoint rejects an empty array and requests that exceed its configured predicate limit.
    </ParamField>
  </Expandable>
</ParamField>

## Predicate Types

| Type | Parameters | Comparison |
| --- | --- | --- |
| `balance` | `address`, `op`, `value` | Compares the account's ETH balance with `value`. |
| `storage` | `address`, `slot`, optional `mask`, `op`, `value` | Compares `storage(address, slot) & mask` with `value`. |
| `block_number` | `op`, `value` | Compares the block number being built with `value`. |
| `flashblock_index` | `op`, `value` | Compares the Flashblock index being built with `value`. |

The supported operators are `<`, `<=`, `=`, `!=`, `>`, and `>=`. Addresses use 20-byte hex encoding. Numeric values use `0x`-prefixed hexadecimal quantity encoding.

For evaluation behavior, examples, and safety considerations, see [Predicates and Safety](/specifications/build-transaction/predicates-and-safety).

## Returns

<ResponseField name="result" type="string">
  The 32-byte hash of the signed EIP-8130 transaction.
</ResponseField>

Returning a hash means that the endpoint accepted the submission. It does not guarantee predicate satisfaction or inclusion.

## Request

<RequestExample>
```bash cURL lines wrap expandable highlight={5,8-10,13-19}
curl "$RPC_URL" \
  -X POST \
  -H "Content-Type: application/json" \
  --data '{
    "jsonrpc": "2.0",
    "id": 1,
    "method": "base_sendRawTransactionValidity",
    "params": [
      "0x79f901...",
      {
        "validity": [
          {
            "type": "balance",
            "params": {
              "address": "0x8ba1f109551bD432803012645Ac136ddd64DBA72",
              "op": ">=",
              "value": "0x1"
            }
          }
        ]
      }
    ]
  }'
```
</RequestExample>

## Error Responses

| Code | Cause | Resolution |
| --- | --- | --- |
| `-32601` | The endpoint does not expose the experimental method. | Use an endpoint that lists validity-transaction support. |
| `-32602` | The transaction cannot be decoded. | Sign and serialize one valid EIP-8130 transaction. |
| `-32602` | The predicate array is empty or exceeds the endpoint limit. | Include at least one predicate and stay within the published limit. |
| `-32602` | A predicate has missing, unknown, or inconsistent fields. | Correct the predicate using the schemas on this page. |
| `-32602` | A storage value contains bits outside its mask. | Expand the mask or reduce the expected value. |
| `-32602` | A block-position predicate can no longer be satisfied. | Sign a replacement with a future block position and validity window. |
| `-32000` | The transaction pool rejects the transaction. | Check funding, nonce or replay identity, fees, duplicates, and replacement pricing. |

```json Invalid Parameters lines wrap expandable highlight={5-6}
}
```

## Monitor the Submission

Use [`base_transactionStatus`](/base-chain/api-reference/flashblocks-api/base_transactionStatus) to check whether the endpoint knows the hash. Use [`eth_getTransactionReceipt`](/base-chain/api-reference/ethereum-json-rpc-api/eth_getTransactionReceipt) to detect inclusion.
