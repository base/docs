# Interfaces

*Solidity interfaces for the B20 system and its supporting precompiles.*

| Interface | Description |
|---|---|
| [`IB20`](https://github.com/base/base-std/blob/bbfb352e9fe2f67bf6ca33ea4d9a7f2fe0cca20d/src/interfaces/IB20.sol) | Core token standard |
| [`IB20Asset`](https://github.com/base/base-std/blob/bbfb352e9fe2f67bf6ca33ea4d9a7f2fe0cca20d/src/interfaces/IB20Asset.sol) | Asset variant of B20 |
| [`IB20Stablecoin`](https://github.com/base/base-std/blob/bbfb352e9fe2f67bf6ca33ea4d9a7f2fe0cca20d/src/interfaces/IB20Stablecoin.sol) | Stablecoin variant of B20 |
| [`IB20Factory`](https://github.com/base/base-std/blob/bbfb352e9fe2f67bf6ca33ea4d9a7f2fe0cca20d/src/interfaces/IB20Factory.sol) | B20 factory precompile |
| [`IPolicyRegistry`](https://github.com/base/base-std/blob/bbfb352e9fe2f67bf6ca33ea4d9a7f2fe0cca20d/src/interfaces/IPolicyRegistry.sol) | Policy registry precompile |
| [`IActivationRegistry`](https://github.com/base/base-std/blob/bbfb352e9fe2f67bf6ca33ea4d9a7f2fe0cca20d/src/interfaces/IActivationRegistry.sol) | Activation registry precompile |
| [`IERC8056`](https://github.com/base/base-std/blob/bbfb352e9fe2f67bf6ca33ea4d9a7f2fe0cca20d/src/interfaces/IERC8056.sol) | Scaled UI Amount standard (Asset variant multiplier) |
| [`IERC165`](https://github.com/base/base-std/blob/bbfb352e9fe2f67bf6ca33ea4d9a7f2fe0cca20d/src/interfaces/IERC165.sol) | Interface detection |

See [`StdPrecompiles.sol`](https://github.com/base/base-std/blob/bbfb352e9fe2f67bf6ca33ea4d9a7f2fe0cca20d/src/StdPrecompiles.sol) for canonical precompile addresses.
