## Goal

Restrict transfers so only eligible holders can receive the asset.

## Before You Start

- You have a B20 asset
- You control the appropriate admin role

## Steps

1. Create an allowlist policy
2. Add eligible addresses
3. Attach the policy to the receiver scope
4. Test an allowed transfer
5. Test a denied transfer
