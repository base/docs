## Features

<AccordionGroup>
<Accordion title="200ms Blocks">

**Base** · Execution

Base will produce native L2 blocks at a 200ms cadence. Each block has its own number, hash, state root, receipts, and unsafe-to-finalized lifecycle. Flashblocks will be deprecated as part of this release.
