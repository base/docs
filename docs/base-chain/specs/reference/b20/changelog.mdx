Per-hardfork, per-feature migration notes for the [B20 token standard](/base-chain/specs/reference/b20). Each Cobalt entry is a focused, code-forward changelog for one scoped feature change that crosses a hardfork boundary. Newest first.

<Note>
B20 method and event signatures are part of the chain's consensus surface. Existing selectors and behavior do not change; the standard grows by addition.
</Note>

## [Beryl](/base-chain/specs/upgrades/beryl/overview) — Initial Release

| Network | Activated |
|---|---|
| Base mainnet | 2026-06-25 |
| Base Sepolia | 2026-06-18 |

Shipped with the [Beryl upgrade](/base-chain/specs/upgrades/beryl/overview).

**Added**

- **[Policy Registry](/base-chain/specs/reference/b20#policy-registry)** — [role-based access control](/base-chain/specs/reference/b20#roles-model), the `PolicyRegistry` singleton with `BLOCKLIST`, `ALLOWLIST`, `UNION`, and `INTERSECT` policy types, two-step admin transfer, and the `ALWAYS_ALLOW`/`ALWAYS_BLOCK` built-ins, [six policy scopes](/base-chain/specs/reference/b20#policy-integration) across transfer/mint/seize, [`seizeWithMemo`](/base-chain/specs/reference/b20#seize) for compliance-driven transfers, and ActivationRegistry gating on state-changing calls.
- **[Token Factory](/base-chain/specs/reference/b20#factory)** — the `B20Factory` singleton for deterministic, variant-encoded token creation with `initCalls` bootstrap; every token ships with full ERC-20 selector/event parity, [`Memo` events](/base-chain/specs/reference/b20#memos) on transfer/mint/burn/seize, [granular pausing](/base-chain/specs/reference/b20#pause), [optional supply caps](/base-chain/specs/reference/b20#supply-cap), [ERC-2612 `permit`](/base-chain/specs/reference/b20#erc-2612-permit--eip-712), and [ERC-7572 `contractURI`](/base-chain/specs/reference/b20#contract-uri-erc-7572).
- **[B20 Asset](/base-chain/specs/reference/b20#asset)** — configurable decimals with `OPERATOR_ROLE`, WAD-precision UI multipliers with scheduled and instant updates, onchain announcements, `batchMint`, and issuer-defined extra metadata.
- **[B20 Stablecoin](/base-chain/specs/reference/b20#stablecoin)** — fixed 6 decimals with a `currency()` ISO code set once at creation.

**Deprecated**

- `burnBlocked` and `BURN_BLOCKED_ROLE`, retained for backwards compatibility. New seizure flows use `seizeWithMemo`.
