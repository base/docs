Subscribe via `eth_subscribe` to receive each transaction as it is pre-confirmed into a Flashblock. Pass `true` as the second parameter to receive full transaction and log data.

<Info>
Only available on Flashblocks WebSocket endpoints: `wss://mainnet.flashblocks.base.org/ws` / `wss://sepolia.flashblocks.base.org/ws`.
</Info>

<Note>
Requires [base/base](https://github.com/base/base) minimum client version v0.8.0.
</Note>

<Warning>
Each subscription emits **one item per WebSocket message**. Events arrive approximately every 200ms. If your handler performs heavy processing per event, throttle or debounce it to avoid blocking.
</Warning>

## Parameters

<ParamField body="subscriptionType" type="string" required>
  Must be `"newFlashblockTransactions"`.
</ParamField>

<ParamField body="full" type="boolean">
  If `true`, each notification includes the full transaction object and associated receipt fields. Defaults to `false` (transaction hash only).
</ParamField>

## Returns

<ResponseField name="result" type="string">
  Hex-encoded subscription ID. Each event notification delivers one transaction per message.

  When `full` is `false` (default), each notification is a transaction hash string.

  When `full` is `true`, each notification is an object with the following fields:

  <Expandable title="Full notification fields (full: true)">
    <ResponseField name="hash" type="string">32-byte transaction hash.</ResponseField>
    <ResponseField name="nonce" type="string">Sender nonce (hex).</ResponseField>
    <ResponseField name="blockHash" type="string">Hash of the Flashblock containing this transaction.</ResponseField>
    <ResponseField name="blockNumber" type="string">Block number (hex).</ResponseField>
    <ResponseField name="transactionIndex" type="string">Index of this transaction in the block (hex).</ResponseField>
    <ResponseField name="from" type="string">20-byte sender address.</ResponseField>
    <ResponseField name="to" type="string">20-byte recipient address. `null` for contract deployments.</ResponseField>
    <ResponseField name="value" type="string">ETH value in wei (hex).</ResponseField>
    <ResponseField name="gas" type="string">Gas limit (hex).</ResponseField>
    <ResponseField name="gasPrice" type="string">Gas price in wei (hex).</ResponseField>
    <ResponseField name="input" type="string">ABI-encoded call data.</ResponseField>
    <ResponseField name="type" type="string">Transaction type: `"0x0"`, `"0x1"`, `"0x2"`, or `"0x7e"` (deposit).</ResponseField>
    <ResponseField name="gasUsed" type="string">Gas used by this transaction (hex). Added in v0.8.0.</ResponseField>
    <ResponseField name="status" type="string">Transaction status: `"0x1"` success, `"0x0"` failure.</ResponseField>
    <ResponseField name="logs" type="array">Array of log objects emitted by this transaction.</ResponseField>
    <ResponseField name="logsBloom" type="string">Bloom filter for the logs in this receipt.</ResponseField>
    <ResponseField name="cumulativeGasUsed" type="string">Cumulative gas used in the block up to this transaction (hex).</ResponseField>
  </Expandable>
</ResponseField>

<Warning>
**Breaking change in v0.8.0:** The `gasUsed` field changed from a decimal integer to a hexadecimal string. If you parse `gasUsed` as a number, update your code to handle hex strings (e.g. `parseInt(gasUsed, 16)`).
</Warning>

## Example

<CodeGroup>
```json Subscribe (hash only)
{"jsonrpc": "2.0", "id": 1, "method": "eth_subscribe", "params": ["newFlashblockTransactions"]}
```

```json Subscribe (full data)
{"jsonrpc": "2.0", "id": 1, "method": "eth_subscribe", "params": ["newFlashblockTransactions", true]}
```
