## Features

<AccordionGroup>
<Accordion title="Base Transactions (EIP-8430)">

**Base** · Transactions

Everest adds Base Transactions, a new transaction type defined by [EIP-8430](https://github.com/ethereum/EIPs/pull/12385) that allows for batching, sponsorship, token gas payments, and high throughput natively. A single transaction can batch calls, have a separate payer cover gas, and use parallel or nonce-free nonces, without bundlers or relays.
