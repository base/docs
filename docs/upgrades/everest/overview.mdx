## Features

<AccordionGroup>
<Accordion title="Base Transactions (EIP-8430)">

**Base** · Transactions

Everest adds Base Transactions, a native transaction type for account abstraction defined by [EIP-8430](https://github.com/ethereum/EIPs/pull/12385). Accounts can batch calls and have gas sponsored by a separate payer within a single protocol-level transaction, without bundlers or relays.
