AgentKit integrates with LangChain, giving your LangChain agent a set of onchain tools it can call to interact with Base. This page covers the setup for both TypeScript and Python.

## Prerequisites

- Node 18+ (TypeScript) or Python 3.10+ (Python)
- A [CDP API key](https://portal.cdp.coinbase.com)
- An OpenAI API key (or any LangChain-compatible LLM)

## How it works

AgentKit provides a set of LangChain-compatible tools. You pass them to a LangChain agent executor, which decides which tools to call based on the user's prompt.

<Tabs>
  <Tab title="TypeScript">
    ```typescript index.ts
    import { AgentKit, CdpWalletProvider } from "@coinbase/agentkit";
    import { getLangChainTools } from "@coinbase/agentkit-langchain";
    import { ChatOpenAI } from "@langchain/openai";
    import { createReactAgent } from "@langchain/langgraph/prebuilt";

    // Initialize AgentKit with a CDP wallet
    const walletProvider = await CdpWalletProvider.configureWithWallet({
      cdpApiKeyName: process.env.CDP_API_KEY_NAME!,
      cdpApiKeyPrivateKey: process.env.CDP_API_KEY_PRIVATE_KEY!,
      networkId: "base-sepolia",
    });

    const agentkit = await AgentKit.from({ walletProvider });

    // Get AgentKit tools as LangChain tools
    const tools = await getLangChainTools(agentkit);

    // Create a LangChain agent
    const llm = new ChatOpenAI({ model: "gpt-4o" });
    const agent = createReactAgent({ llm, tools });

    // Run the agent
    const result = await agent.invoke({
      messages: [{ role: "user", content: "What is my ETH balance?" }],
    });

    console.log(result.messages.at(-1)?.content);
    ```
  </Tab>

  <Tab title="Python">
    ```python main.py
    from coinbase_agentkit import AgentKit, AgentKitConfig, CdpWalletProvider
    from coinbase_agentkit_langchain import get_langchain_tools
    from langchain_openai import ChatOpenAI
    from langgraph.prebuilt import create_react_agent

    # Initialize AgentKit with a CDP wallet
    wallet_provider = CdpWalletProvider.configure_with_wallet(
        cdp_api_key_name=os.environ["CDP_API_KEY_NAME"],
        cdp_api_key_private_key=os.environ["CDP_API_KEY_PRIVATE_KEY"],
        network_id="base-sepolia",
    )

    agentkit = AgentKit(AgentKitConfig(wallet_provider=wallet_provider))

    # Get AgentKit tools as LangChain tools
    tools = get_langchain_tools(agentkit)

    # Create a LangChain agent
    llm = ChatOpenAI(model="gpt-4o")
    agent = create_react_agent(llm, tools)

    # Run the agent
    result = agent.invoke({
        "messages": [{"role": "user", "content": "What is my ETH balance?"}]
    })

    print(result["messages"][-1].content)
    ```
  </Tab>
</Tabs>

## Available tools

AgentKit registers the following tools with LangChain:

| Tool | Description |
|------|-------------|
| `get_wallet_details` | Return the agent's wallet address and network |
| `get_balance` | Check ETH or ERC-20 token balance |
| `native_transfer` | Send ETH to an address |
| `erc20_transfer` | Transfer an ERC-20 token |
| `trade` | Swap tokens via an onchain DEX |
| `deploy_token` | Deploy a new ERC-20 contract |
| `wrap_eth` | Wrap ETH to WETH |
| `request_faucet_funds` | Request testnet funds from the Base Sepolia faucet |

## Adding custom tools

Combine AgentKit tools with your own LangChain tools:

<Tabs>
  <Tab title="TypeScript">
    ```typescript
    import { tool } from "@langchain/core/tools";
    import { z } from "zod";

    const myTool = tool(
      async ({ query }) => {
        // your custom logic
        return `Result for: ${query}`;
      },
      {
        name: "my_custom_tool",
        description: "Does something custom",
        schema: z.object({ query: z.string() }),
      }
    );

    const allTools = [...(await getLangChainTools(agentkit)), myTool];
    const agent = createReactAgent({ llm, tools: allTools });
    ```
  </Tab>

  <Tab title="Python">
    ```python
    from langchain_core.tools import tool

    @tool
    def my_custom_tool(query: str) -> str:
        """Does something custom."""
        return f"Result for: {query}"

    all_tools = get_langchain_tools(agentkit) + [my_custom_tool]
    agent = create_react_agent(llm, all_tools)
    ```
  </Tab>
</Tabs>
