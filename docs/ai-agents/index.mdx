## How this section is organized

This section gives your AI agent the tools to act autonomously onchain. Start with **[Wallet Setup](/ai-agents/setup/wallet-setup)** to give your agent a funded wallet, then optionally **[register its identity](/ai-agents/setup/agent-registration)**. From there, follow a quickstart — build an agent that [pays for API access](/ai-agents/quickstart/payments) or one that [trades on Base](/ai-agents/quickstart/trading). The **[Payments](/ai-agents/payments/x402-protocol)** and **[Trading](/ai-agents/trading/data-fetching)** sections cover each capability in depth.

<Note>
Before using either quickstart, complete the [wallet setup](/ai-agents/setup/wallet-setup) and optionally [register your agent](/ai-agents/setup/agent-registration) for discoverability and identity verification.
</Note>
