Morpho is a lending protocol on Base. The plugin drives the [Morpho MCP server](https://mcp.morpho.org/) for vault discovery, position queries, and prepare-style tools that return unsigned calldata. Base MCP's `send_calls` wraps the calldata into a single approval.

**Chain:** Base mainnet.

**Operations:** deposit, withdraw, supply, borrow, repay, supply/withdraw collateral, plus reads for vaults, markets, and positions.

## Install alongside Base MCP

```json mcp.json
{
  "mcpServers": {
    "base-mcp": { "url": "https://mcp.base.org" },
    "morpho":       { "url": "https://mcp.morpho.org/" }
  }
}
```

Claude Code: `claude mcp add morpho --transport http https://mcp.morpho.org/`

## Pattern

Morpho's `prepare_*` tools return `{ calls, chainId }`. The assistant maps the returned chain ID to Base MCP's `chain` name, calls `send_calls`, and polls `get_request_status` once you approve in Base Account.
