Reference addresses for the smart contracts that power agent identity and payments on Base.

## Mainnet (Base)

| Contract | Address | Description |
|----------|---------|-------------|
| ERC-8004 Agent Registry | `0x0000000000000000000000000000000000000000` | Public directory for agent registration and discovery |
| ERC-8128 Verification | `0x0000000000000000000000000000000000000000` | On-request signature verification for agents |
| x402 Payment Facilitator | `0x0000000000000000000000000000000000000000` | Settles x402 payments between agents and services |

## Protocol references

| Protocol | Standard | Purpose |
|----------|---------|---------|
| Agent Registry | ERC-8004 | Onchain directory mapping agent names to public keys and endpoints |
| Agent Verification | ERC-8128 | Runtime signature verification proving request origin |
| x402 Payments | HTTP 402 + USDC | Pay-per-request stablecoin payments between agents and services |
