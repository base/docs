## x402 and the Base Account MCP

The Base Account MCP supports sending and swapping tokens directly. **x402 payment protocol** — which lets agents pay for API access per-request in stablecoins — is not yet supported through the Base Account MCP.

<Note>
x402 support for the Base Account MCP is coming soon.
</Note>

## For x402 payments today: CDP Agentic Wallet

If you need your agent to make or accept x402 payments right now, use the [CDP Agentic Wallet](https://docs.cdp.coinbase.com/agentic-wallet/welcome):

```bash Terminal
npx skills add coinbase/agentic-wallet-skills
```

The CDP Agentic Wallet skill bundle includes `pay-for-service`, `search-for-service`, and `monetize-service` — the full x402 client and server stack.
