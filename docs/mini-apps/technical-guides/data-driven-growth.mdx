## Base Build Powers Your Growth

[Base.dev](https://www.base.dev/) is the builder tool platform that helps developers build, grow, and earn through miniapps on Base. It provides real-time analytics and user behavior insights to optimize your app's performance and engagement, helping builders understand exactly how users interact with their miniapps and identify the features that drive retention and growth.

<Step title="Add Base Builder Object to your Manifest">
Import a mini app by adding the `baseBuilder` object into your manifest. 

The address for the `allowedAddresses` field should be associated with your Base.dev account.

```json highlight={4-5}
{
  "accountAssociation": { ... },
  "frame": { ... },

    "allowedAddresses": ["0x..."]
  }
}
```

## Available Analytics Data

The Base Build dashboard provides you with real-time analytics as users interact with your miniapp across the following metrics:

### User Engagement Metrics

#### Active & New Users

Total number of Base App users who have opened your mini app:

- **New Users**: First-time opens
- **Active Users**: Return visits after initial open

<Tip>Track this to measure user retention and identify if your app encourages repeat usage.</Tip>

#### Number of Opens

The total number of times users opened your application.

<Tip> Use this metric to understand overall app popularity and correlate with feature releases or marketing efforts.</Tip>

#### Total Session Time

Total time users have spent in the application across all sessions.


#### Median Session Time

The median duration of all user sessions. Longer sessions typically indicate higher engagement with your content. 

<Tip>Compare session times across different features to identify what keeps users engaged.</Tip>

#### Entry Points

Traffic sources showing how users discover and enter your application:

- **Base App Home**: Users discover your app from the home screen
- **Base App Search**: Users find your app through search
- **Base App Messaging**: Users access your app from messaging
- **Base App Feed**: Users click through from their feed
- **Base App Social**: Users arrive from social features
- **Other**: Additional entry points and referral sources

<Tip>Optimize your presence on high-traffic entry points and investigate low-performing sources to improve discoverability.</Tip>
