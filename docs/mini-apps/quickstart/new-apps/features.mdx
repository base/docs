The template wires up core MiniKit pieces so you can ship v0 fast.

## Providers and initialization

The scaffold includes complete MiniKit setup:

```tsx
// MiniKitProvider configuration
<MiniKitProvider
  apiKey={process.env.NEXT_PUBLIC_ONCHAINKIT_API_KEY}
  chain={base}
  config={{
    appearance: {
      mode: 'auto',
      theme: 'snake',
      name: process.env.NEXT_PUBLIC_ONCHAINKIT_PROJECT_NAME,
      logo: process.env.NEXT_PUBLIC_ICON_URL,
    },
  }}
>
  {children}
</MiniKitProvider>
```

```tsx
// Frame initialization
const { setFrameReady, isFrameReady, context } = useMiniKit();

useEffect(() => {
  if (!isFrameReady) {
    setFrameReady();
  }
}, [setFrameReady, isFrameReady]);

// Context provides:
// context.user.fid - Farcaster ID
// context.client.added - User added app  
// context.location - Launch location
```

## Buttons and actions

### Save Frame Functionality
```tsx
const addFrame = useAddFrame();

const handleAddFrame = async () => {
  const result = await addFrame();
  if (result) {
    console.log('Frame added:', result.url, result.token);
    // Save url and token to database for notifications
  }
};
```

### External Links and Navigation
```tsx
const openUrl = useOpenUrl();

const handleExternalLink = () => {
  openUrl('https://example.com');
};
```

### Close Frame
```tsx
const close = useClose();

const handleClose = () => {
  close();
};
```
