The clearest role for AI on Base today is payments. With the [x402](https://docs.cdp.coinbase.com/x402/welcome) standard, an agent can pay for data and services on its own — one request at a time, in USDC, with no API keys or accounts. When an endpoint returns `402 Payment Required`, an x402 client pays the stated price on Base and retries automatically.
