Represent a real-world asset with the [B20 Asset standard](/specifications/b20/specification-overview#asset). Configure precision and issuer roles, distribute units, restrict eligible holders, and run distributions through one ERC-20-compatible surface built into Base. The guides below use a stock token as the worked example; the same flows apply to other asset types.
