Accept dollars on Base. USDC is a fully-backed digital dollar that settles quickly for low network fees, without card-network chargebacks or processor fees. [Base Pay](/sdks/base-account/reference/base-pay/pay) provides one-tap checkout and subscriptions for Base Account users; [x402](https://docs.x402.org/introduction) separately lets software agents pay HTTP services.

If you accept a B20 token, standard ERC-20 transfers work unchanged and memo variants can carry an order reference in the payment transaction.
