## Accelerate

### Builder Codes

The Base team provides grants very selectively. The first step to be eligible for grants is to integrate [Builder Codes](/specifications/builder-codes/overview).

These are unique identifiers that tag your app's transactions so Base can attribute onchain activity back to you — and we wanted to make sure you're set up.

### Builder Grant Program

Get up to $5,000 in grants, GTM and product support for actively building on Base across:

1. Prediction markets
2. Token launchpads
3. DeFi 2.0 — lending, borrowing, looping, yield generation, vaults, tokenized equities
4. Agents — commerce, x402 implementations, autonomous trading
5. Products focusing on new asset creation
6. Consumer apps focused on transaction growth

Apply to be included in our next cohort.
