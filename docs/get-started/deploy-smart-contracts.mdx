Welcome to the Base deployment quickstart guide! This comprehensive walkthrough will help you set up your environment and deploy smart contracts on Base using Foundry.

## What You'll Achieve

By the end of this quickstart, you'll be able to:

- Set up your development environment to deploy on Base
- Deploy your smart contracts to Base Sepolia testnet
- Connect and verify your deployed smart contracts

<Tip>
**Why Base?**

Base is a fast, low-cost, builder-friendly Ethereum L2 built to bring the next billion users onchain. By following this guide, you'll join a vibrant ecosystem of developers, creators, and innovators building a global onchain economy.
</Tip>

## Set Up Your Development Environment

<Steps>
  <Step title="Create Project Directory">
    Create a new project directory and navigate into it:
    ```bash filename="terminal"
    mkdir my-base-project && cd my-base-project
    ```
  </Step>

  <Step title="Install Foundry">
    Install Foundry, a fast and modular toolkit for Ethereum application development:
    ```bash filename="terminal"
    curl -L [https://foundry.paradigm.xyz](https://foundry.paradigm.xyz) | bash
    foundryup
    ```
    This installs Foundry and updates it to the latest version.
  </Step>

  <Step title="Initialize Solidity Project">
    Initialize a new Solidity project:
    ```bash filename="terminal"
    forge init
    ```
    Your Foundry project is now ready. You'll find an example contract in the `src` directory (`/src/Counter.sol`), which we will use for this guide.
  </Step>
</Steps>

<Tip>
Foundry provides a suite of tools for Ethereum application development, including Forge (testing), Cast (chain interaction), and Anvil (local node). Learn more in the official [Foundry Book](https://book.getfoundry.sh/).
</Tip>

## Configure Foundry with Base

To deploy your smart contracts to Base, you need a node connection and a funded private key.

### 1. Set Up Node Connection

<Steps>
  <Step title="Create Environment File">
    Create a `.env` file in your project root directory:
    ```bash filename="terminal"
    touch .env
    ```
  </Step>

  <Step title="Add Base RPC URLs">
    Add the Base network RPC URLs to your `.env` file:
    ```env filename=".env"
    BASE_RPC_URL="[https://mainnet.base.org](https://mainnet.base.org)"
    BASE_SEPOLIA_RPC_URL="[https://sepolia.base.org](https://sepolia.base.org)"
    ```
  </Step>

  <Step title="Load Environment Variables">
    Load your environment variables into your shell session:
    ```bash filename="terminal"
    source .env
    ```
  </Step>
</Steps>

<Tip>
Base Sepolia is the official test network for Base. You can obtain free Base Sepolia ETH from available [network faucets](/base-chain/network-information/network-faucets).
</Tip>

### 2. Secure Your Private Key

<Steps>
  <Step title="Import Key to Keystore">
    Store your private key securely using Foundry's encrypted keystore:
    ```bash filename="terminal"
    cast wallet import deployer --interactive
    ```
  </Step>

  <Step title="Set Keystore Password">
    When prompted, enter your private key and set a strong password.
  </Step>
</Steps>

<Warning>
Never share or commit your raw private key. Keystores in `~/.foundry/keystores` are stored securely outside your repository.
</Warning>

## Deploy Your Contracts

<Steps>
  <Step title="Deploy to Base Sepolia">
    Run the `forge create` command to compile and deploy your contract:
    ```bash filename="terminal"
    forge create ./src/Counter.sol:Counter --rpc-url $BASE_SEPOLIA_RPC_URL --account deployer
    ```
    *Note: The deployment format is `<contract-path>:<contract-name>`.*
  </Step>

  <Step title="Save Deployed Address">
    Copy the deployed contract address from the console output and save it to your `.env` file:
    ```env filename=".env"
    COUNTER_CONTRACT_ADDRESS="0x..."
    ```
  </Step>

  <Step title="Reload Environment">
    Reload your environment variables:
    ```bash filename="terminal"
    source .env
    ```
  </Step>
</Steps>

---

### Verify Your Deployment

<Steps>
  <Step title="Check Explorer">
    View your transaction on [Sepolia Basescan](https://sepolia.basescan.org/).
  </Step>

  <Step title="Interact via Cast">
    Use Cast to query your deployed contract directly from the command line:
    ```bash filename="terminal"
    cast call $COUNTER_CONTRACT_ADDRESS "number()(uint256)" --rpc-url $BASE_SEPOLIA_RPC_URL
    ```
    This should return `0`, matching the initial value of the `Counter` contract.
  </Step>
</Steps>

<Check>
**Congratulations!** You have successfully deployed and verified your smart contract on Base Sepolia!
</Check>
