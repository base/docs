A native account abstraction (EIP-8130) account, created in this page and running
against the live Vibenet devnet. Step one funds it from the faucet. Step two
sends 1 USDV to a random address — a real ERC-20 transfer, in a transaction that
also deploys the account.

There is no wallet, no extension, and no connect prompt anywhere in this flow.

<Warning>
**This page is for testing only and will not ship to the published docs.**

It exists to demonstrate that a docs page can run real onchain interactions
rather than a scripted mock. It runs against a devnet that can be reset without
notice, and USDV is unbacked test currency with no value.
</Warning>
