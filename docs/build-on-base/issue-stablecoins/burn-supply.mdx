When a holder redeems for fiat, they return the tokens and you burn them, keeping circulating supply matched to reserves. Burning is gated by `BURN_ROLE` and burns from the caller's own balance.

## Burn on redemption

```bash Terminal
# Burn 400 MUSD held by your redemption address.
base-cast send $TOKEN_ADDRESS "burn(uint256)" 400000000 \
  --rpc-url $RPC_URL --private-key $REDEMPTION_KEY
```

Use `burnWithMemo` to tie the burn to the fiat payout. To reclaim tokens from a blocked account instead, see [Recover funds](/build-on-base/issue-stablecoins/recover-funds).
