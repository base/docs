Run a 2-for-1 stock split by setting the B20 Asset multiplier to `2e18`. Raw balances stay unchanged, while `scaledBalanceOf` and conversion helpers expose the post-split share amounts.

## Update the multiplier

```bash Terminal lines wrap
# WAD precision is 1e18, so 2e18 represents a 2-for-1 multiplier.
base-cast send $TOKEN_ADDRESS "updateMultiplier(uint256)" 2000000000000000000 \
  --rpc-url $RPC_URL --private-key $OPERATOR_KEY

base-cast call $TOKEN_ADDRESS "scaledBalanceOf(address)(uint256)" \
  $ALICE --rpc-url $RPC_URL
```

<Warning>
Integrations that present shares to users must distinguish raw token units from scaled balances and use B20's conversion helpers consistently.
</Warning>
