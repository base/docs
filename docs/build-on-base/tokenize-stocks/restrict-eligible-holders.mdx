Create an allowlist in the [Policy Registry](/base-chain/specs/upgrades/beryl/b20#policy-registry), then apply it when shares are issued, sent, or received. Accounts remain ineligible until the policy admin adds them.

## Apply the holder policy

```solidity script/RestrictHolders.s.sol lines wrap highlight={8-9,13-15}
IB20 token = IB20(vm.envAddress("TOKEN_ADDRESS"));
address admin = vm.envAddress("ACCOUNT_ADDRESS");

address[] memory approved = new address[](2);
approved[0] = vm.envAddress("ALICE_ADDRESS");
approved[1] = vm.envAddress("BOB_ADDRESS");

vm.startBroadcast();
uint64 policyId = StdPrecompiles.POLICY_REGISTRY.createPolicy(
    admin, IPolicyRegistry.PolicyType.ALLOWLIST
);
StdPrecompiles.POLICY_REGISTRY.updateAllowlist(policyId, true, approved);

token.updatePolicy(B20Constants.MINT_RECEIVER_POLICY, policyId);
token.updatePolicy(B20Constants.TRANSFER_SENDER_POLICY, policyId);
token.updatePolicy(B20Constants.TRANSFER_RECEIVER_POLICY, policyId);
vm.stopBroadcast();
```

<Warning>
An allowlist denies every account that is not a member. Confirm the policy exists and seed the intended holders before binding it to the token.
</Warning>
