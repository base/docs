Use the [B20 Asset variant](/base-chain/specs/upgrades/beryl/b20#asset) to represent a class of tokenized shares with configurable precision, issuer roles, supply controls, and metadata. This example creates Example Corp Class A (`EXM`) with six decimals.

## Create the token

Encode the Asset parameters and bootstrap configuration with `B20FactoryLib`, then call the B20 Factory:

```solidity script/CreateStockToken.s.sol lines wrap highlight={12-13,26-28}
address account = vm.envAddress("ACCOUNT_ADDRESS");

B20FactoryLib.B20AssetRoleHolders memory holders = B20FactoryLib.B20AssetRoleHolders({
    minter: account,
    burner: address(0),
    burnBlocker: account,
    pauser: account,
    unpauser: account,
    metadataAdmin: account,
    operator: account
});
bytes[] memory roleCalls = B20FactoryLib.buildRoleGrants(holders);

bytes[] memory settings = new bytes[](2);
settings[0] = B20FactoryLib.encodeUpdateSupplyCap(1_000_000e6);
settings[1] = B20FactoryLib.encodeUpdateExtraMetadata(
    "security-id", "EXAMPLE-CLASS-A"
);

bytes memory params = B20FactoryLib.encodeAssetCreateParams(
    "Example Corp Class A", "EXM", account, 6
);
bytes[] memory initCalls = B20FactoryLib.concat(roleCalls, settings);

token = StdPrecompiles.B20_FACTORY.createB20(
    IB20Factory.B20Variant.ASSET,
    keccak256("example-corp-class-a"),
    params,
    initCalls
);
```

<Note>
The supply cap is a technical ceiling on token supply. For Base Foundry setup, network configuration, imports, and broadcasting, complete [Launch a B20 token](/get-started/launch-b20-token) first.
</Note>
