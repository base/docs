Charge a customer in USDC with one call to [`pay()`](/sdks/base-account/reference/base-pay/pay). You set the dollar amount and your receiving address; the customer approves in their Base Account, gas is sponsored automatically, and the payment settles on Base in under two seconds.

## Charge the customer

```ts checkout.ts
import { pay } from '@base-org/account';

// Amount is in USD; USDC is used under the hood.
const payment = await pay({
  amount: '5.00',
  to: '0xYourReceivingAddress',
  testnet: false, // set true for Base Sepolia
});

console.log(`Payment sent — id: ${payment.id}`);
```

Prefer a native control? Drop in the [Base Pay Button](/sdks/base-account/reference/ui-elements/base-pay-button) and call `pay()` from its `onClick`.
