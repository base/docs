Never fulfill an order on a client-side confirmation alone. Check the payment on your backend with [`getPaymentStatus()`](/sdks/base-account/reference/base-pay/getPaymentStatus), then match the `sender` and `amount` to the order and record the id so it can't be reused.

## Confirm before fulfilling

```ts confirm-order.ts
import { getPaymentStatus } from '@base-org/account';

const { status, sender, amount } = await getPaymentStatus({ id, testnet: false });

if (status !== 'completed') throw new Error('Payment not completed');
if (sender.toLowerCase() !== order.payer.toLowerCase()) throw new Error('Wrong sender');
if (amount !== order.total) throw new Error('Amount mismatch');
if (await alreadyProcessed(id)) throw new Error('Replayed payment');

await markProcessed(id);
await fulfill(order);
```

<Warning>
`testnet` must match the value used in the original [`pay()`](/sdks/base-account/reference/base-pay/pay) call, and you must track processed ids to stop replay and impersonation.
</Warning>
