## Browse the Catalog

This preview tests a catalog designed for a large and frequently changing list. It keeps the page usable by showing 25 records at a time, while allowing developers to search by symbol, company name, ISIN, or contract address.

## Design Notes

- The catalog shows token identity fields first: symbol, underlying asset, ISIN, and contract address.
- Search and pagination avoid rendering or scanning a long static table manually.
- A production catalog would read from the [tokenized stocks API](https://api.coinbase.com/v1/tokenized-stocks), rather than use page content as the source of truth.
- This is intentionally a separate preview page. It does not change the current tokenized-stocks integration guide.
