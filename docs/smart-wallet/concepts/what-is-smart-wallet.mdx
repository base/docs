---
title: "What is Base Account?"
---

Base Account is a multi-chain self-custodial cryptocurrency wallet that enables users to create an onchain account in seconds with no app or extension required, thanks to its reliance on [Passkeys](https://passkeys.com). It is often described as a more secure and user-friendly way to interact with onchain applications.

## Key Features

Base Account combines the best features of a wallet and an app-specific account:

- **Instant Account Creation**: Create an account in seconds using passkeys - no seed phrases or downloads required
- **Multi-Chain Support**: Works across multiple blockchain networks seamlessly
- **Enhanced Security**: Built-in passkey authentication provides enterprise-grade security
- **Developer-Friendly**: Easy integration with existing applications and frameworks

## What can you do with Base Account?

### For Users
- **[Use MagicSpend](/smart-wallet/concepts/features/built-in/MagicSpend)**: Use Coinbase balances onchain without manual transfers
- **[Get Free Sponsored Transactions](/smart-wallet/concepts/base-gasless-campaign)**: Use Paymaster to sponsor transactions and get qualified for up to $15k in gas credits
- **Seamless Authentication**: Sign in with passkeys across all supported applications
- **Cross-App Identity**: Maintain the same account, identity, and assets across different apps

### For Developers
- **[Support Sub Accounts](/smart-wallet/guides/sub-accounts)**: Improve user experience with embedded accounts controlled by their Base Account, eliminating the need for users to sign a transaction for every onchain action
- **[Support Spend Permissions](/smart-wallet/guides/spend-permissions)**: Enable third-party signers to spend user assets with controlled permissions
- **[Batch Transactions](/smart-wallet/guides/batch-transactions)**: Execute multiple operations in a single transaction for better UX
- **[Sponsored Transactions](/smart-wallet/guides/paymasters)**: Pay for your users' gas fees to remove friction
