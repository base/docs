Cobalt is a Base network upgrade that introduces native token infrastructure and account abstraction at the protocol level.

## Features

| Feature | Summary |
|---------|---------|
| [B20 Token Standard](/specs/cobalt/b20/overview) | Native ERC-20 superset with built-in compliance: transfer policies, freeze-and-seize, role-based access control, memos, and supply caps |
| [EIP-8130](/base-chain/specs/upgrades/cobalt/eip-8130) | Native account abstraction enabling smart contract wallets without bundlers |

## Precompile addresses

These addresses are identical on every network where Cobalt features are active (Mainnet, Base Sepolia, Vibenet, and local `base-anvil`).

| Precompile | Address |
|---|---|
| [B20Factory](/specs/cobalt/b20/overview#8-factory-and-deployment) | `0xB20f000000000000000000000000000000000000` |
| Activation Registry | `0x8453000000000000000000000000000000000001` |
| [Policy Registry](/specs/cobalt/b20/overview#4-policy-registry) | `0x8453000000000000000000000000000000000002` |
