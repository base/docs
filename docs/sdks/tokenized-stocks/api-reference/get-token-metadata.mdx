---

## Example

Use the token symbol, including its token suffix, such as `TSLAc`. Ticker lookup is case-insensitive.

```bash cURL
curl https://api.coinbase.com/v1/tokenized-stocks/metadata/TSLAc
```

The response contains `contract_address`, `name`, `symbol`, `description`, `image`, and `prospectus_url`. The image and prospectus URLs are stable API links that redirect to the current assets. A `prospectus_url` does not guarantee that a PDF is currently cached; check [List Cached Prospectuses](/sdks/tokenized-stocks/api-reference/list-cached-prospectuses) for available tickers.
