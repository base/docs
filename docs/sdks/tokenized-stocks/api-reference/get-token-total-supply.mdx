---
title: "Get Token Total Supply"
description: "Return a tokenized stock's ERC-20 total supply, normalized by the token's decimals."
openapi: "openapi/tokenized-equities.json GET /v1/tokenized-stocks/total-supply/{contract_address}"
---

## Example

Replace `CONTRACT_ADDRESS` with a token address from the [Base assets page](https://www.base.org/assets) or the [List Tokenized Stocks](/sdks/tokenized-stocks/api-reference/list-tokenized-stocks) endpoint.

```bash cURL
curl https://api.coinbase.com/v1/tokenized-stocks/total-supply/CONTRACT_ADDRESS
```
