---
title: "List Cached Prospectuses"
description: "List token tickers with cached approved prospectuses and their ISINs when known."
openapi: "openapi/tokenized-equities.json GET /v1/tokenized-stocks/prospectuses"
---

## Example

```bash cURL
curl https://api.coinbase.com/v1/tokenized-stocks/prospectuses
```

The response contains a `prospectuses` array, sorted alphabetically by uppercase ticker. Each entry includes `ticker` and, when known, the underlying equity's `isin`. It does not include upstream PDF URLs. Use the ticker with [Get Token Prospectus](/sdks/tokenized-stocks/api-reference/get-token-prospectus) to retrieve the PDF.

The prospectus cache refreshes in the background. Before a successful refresh, the cache can be empty and the `prospectuses` field can be omitted. This is a prospectus-availability list, not a list of tokens available for trading.
