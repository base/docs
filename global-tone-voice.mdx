---

## Purpose

This document defines the tone and voice guidelines for Base documentation to ensure consistency across all content.

## Tone

- Clear and concise
- Developer-first
- Practical and actionable
- Avoid marketing-heavy language

## Voice

- Direct and instructional
- Use active voice
- Prefer short sentences over complex phrasing

## Writing Guidelines

- Use examples where possible
- Avoid ambiguity
- Keep formatting consistent with existing docs
- Use code blocks for all commands and snippets

## Consistency

All documentation should follow these principles to provide a predictable and high-quality developer experience.
